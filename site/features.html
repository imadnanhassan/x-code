Code with clarity.

  • ✓ Emmet abbreviations, code snippets, and your own via .xcode/snippets.json

Git, without leaving the editor.

Terminal & tasks

Stay in flow.

A real, built-in terminal — PowerShell, bash or zsh — with multiple sessions, no native build step required. Run your project's npm/yarn/pnpm scripts straight from a task runner.

  • ✓ Real PTY sessions, not a fake shell
  • ✓ Multiple terminals, "open terminal here"
  • ✓ Auto-discovers package.json scripts + .xcode/tasks.json

Linting, formatting & preview

Real rules. Real feedback.

Xcode runs your project's own ESLint and Prettier straight from node_modules — real rules, quick fixes, format on save. Open a live preview pane beside the editor, or fire off an API request without leaving your file.

  • ✓ Project-aware ESLint + Prettier, fix-all & format on save
  • ✓ Live preview pane — dev server or local file, responsive sizes
  • ✓ Built-in API client — write .http requests, hit Send
