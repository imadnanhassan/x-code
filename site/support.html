Frequently asked questions

General

Is this related to Apple's Xcode? +
No. Xcode by DataDropX is an independent, cross-platform code editor. It is not made by, endorsed by, or affiliated with Apple, and it does not build iOS/macOS apps.
Is it free and open source? +
Yes — MIT licensed, forever free. Source, releases and issues all live on GitHub.
How much memory does it use? +
Around 150–230 MB idle on a typical machine, versus ~350 MB – 1 GB+ for a full IDE. The editor engine only loads once you open a file, and hardware acceleration is a toggle in Settings → Performance.
Can I bring my VS Code settings? +
Yes. Settings → Import VS Code Settings reads your settings.json and maps font, theme, tab size, word wrap, format-on-save, auto-save and more.

Platforms & roadmap

What platforms does it run on? +
Windows 10/11 (x64) is available today as a one-click .exe installer. macOS and Linux builds are in progress — star the repo to get notified when they ship.
Is the AI assistant available yet? +
Not yet — it's next on the roadmap: multi-file edits with a reviewable diff, generate/explain/refactor in place, and your own API key. Everything else on the features page ships today.

Installation & updates

Windows says "Unknown publisher" — is that safe? +
Yes. The installer isn't code-signed yet (that costs a yearly certificate), so SmartScreen flags it as unrecognized rather than malicious. Click More info → Run anyway. You can always verify the build against its checksum in the release's latest.yml file on GitHub.
How do updates work? +
Xcode checks for updates in the background and downloads them automatically. When one's ready, an in-app banner lets you install on restart — no installer wizard, no extra clicks.
The terminal isn't working — what do I do? +
The built-in terminal ships with prebuilt binaries and needs no setup. If it still doesn't open, please file an issue with your Windows version and the error you see.

Privacy

Does Xcode collect my data? +
No telemetry, no analytics, no accounts. The only network calls Xcode makes are checking GitHub for a newer release and any HTTP requests you explicitly send from the built-in API client.
