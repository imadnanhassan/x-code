Questions

Is this related to Apple's Xcode? +
No. Xcode by DataDropX is an independent cross-platform code editor. It is not made by, endorsed by, or affiliated with Apple, and it does not build iOS/macOS apps.
What platforms does it run on? +
Windows is available now as a portable build and installer. macOS and Linux builds are in progress — star the repo to get notified.
How much memory does it use? +
Around 150–230 MB idle on a typical machine, versus ~350 MB – 1 GB+ for a full IDE. The editor engine only loads when you open a file, and hardware acceleration is a toggle.
Is the AI assistant available yet? +
Not in the current build — it's the next feature on the roadmap. Everything else (terminal, Emmet, themes, Markdown preview, cross-file search, VS Code settings import) ships today.
Is it free and open source? +
Yes — MIT licensed. Source, releases and issues are on GitHub.
Can I bring my VS Code settings? +
Yes. Settings → Import VS Code Settings reads your settings.json and maps font, theme, tab size, word wrap, format-on-save, auto-save and more.
